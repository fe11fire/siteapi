# Проверки

[Обзор проекта](../readme.md)

Тесты — автономные PHP-скрипты с явными проверками. Запускайте каждый отдельным процессом: некоторые определяют одноимённые вспомогательные функции или подмены классов.

## Без внешних сервисов

| Команда | Что проверяет |
|---|---|
| php tests/app.php | Генератор, отказ перезаписи, запуск без настроек/middleware, HTML/JSON 404/500, буфер |
| php tests/settings.php | JSON, типы, default, окружение, null и ошибки |
| php tests/database.php | Настоящий PDO/SQLite: типы bindings, транзакции, NULL, условия, COUNT |
| php tests/database-logging.php | Отсутствие секретов в логах, PDO, ErrorHandler, отказ логгера |
| php tests/messenger.php | Выбор канала, Telegram payload, порядок, частичная ошибка, подмена транспорта |
| php tests/email.php | Адаптер email с двойником PHPMailer, экранирование, вложения, отказ |
| php tests/logger.php | Enum/строка, default, неверный провайдер |
| php tests/files.php | Чтение/создание каталогов, вложенность, циклическая ссылка |
| php tests/secret.php | Ленивый старт сессии, токены, проверка, ошибка после вывода |
| php tests/vars.php | Имена JS-переменных, экранирование script, ошибки JSON |
| php tests/redirect.php | Построение URL, query string, фрагмент и кодирование |
| php tests/router-reset.php | Сброс состояния |
| php tests/router-matching.php | Строгое сопоставление имён |
| php tests/router-params.php | Создание/замена параметров без потери типа |
| php tests/string-code.php | Алфавит, регистр, длина и дефисы |
| php tests/string-plural.php | Отрицательные числа, ноль, границы int |

Для SQLite-сценариев нужен pdo_sqlite. Сценарии с временными файлами требуют записи в системный временный каталог; тест ссылок — возможности создавать symlink. Ожидаемые отказы могут писать диагностические сообщения в stderr, но успешный процесс завершается кодом 0.

## Локальная HTTP-интеграция

```sh
php tests/curl.php
```

Создаёт временный HTTP-сервер только на loopback и проверяет 200/500, JSON, 204, таймаут, отказ соединения и отсутствие секретов в журнале. Нужны proc_open и разрешённые локальные сокеты. Внешний API не вызывается.

## Настоящий кэш

```sh
REDIS_HOST=127.0.0.1 REDIS_PORT=6379 \
MEMCACHED_HOST=127.0.0.1 MEMCACHED_PORT=11211 \
php tests/cache.php
```

Нужны Composer autoload, тестовые Redis/Memcached и PHP-расширение Memcached. Сценарий использует уникальное пространство ключей и удаляет свои записи, не очищая сервер целиком.

## Проверка установки

```sh
composer validate --no-check-publish
composer check-platform-reqs
```

Проверка платформы может быть выполнена по lock-файлу до установки: `composer check-platform-reqs --lock`. Composer пока предупреждает об отсутствии лицензии: лицензия должна быть выбрана владельцем проекта.

## Границы подтверждённого

В ходе текущей проверки прошли автономные сценарии и локальная HTTP-интеграция. Проверка настоящего кэша требует отдельной среды и не включена в подтверждённый автономный прогон. Не подтверждены реальная доставка SMTP/Telegram, все MySQL-особенности, production-конфигурация сервера и работа под минимальной версией PHP 8.1.

Следующий этап проверки: установить полный набор расширений и Composer-зависимостей, выполнить cache.php, проверить MySQL и отправить тестовые сообщения разрешённым получателям. Автономные подмены не заменяют эти проверки. Здесь не заявляются проценты покрытия, нагрузочные результаты или production-ready статус.

Проверка JSON-ответов: `php tests/response.php`. Запускает локальный HTTP-сервер и проверяет статусы, заголовки, middleware, очистку вывода, finally, HEAD и ошибку кодирования. Нужны ext-curl, proc_open и локальные сокеты; внешние сервисы не используются.
